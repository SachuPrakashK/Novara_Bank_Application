# Outbox Monitoring Rules

The demonstration reflects only supported concepts: pending/published counts and oldest pending age. Failed projections, attempts, retry candidates, quarantine and consumer health are shown unavailable because current outbox rows do not represent them.

Manual replay and deletion are disabled. Future recovery needs authorization, idempotency analysis, immutable action audit, privacy-safe diagnostics, retry/quarantine schema, alerts and named on-call ownership. No external monitoring is claimed.
